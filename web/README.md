# 재택의료저널 — 홈페이지 디자인 초안

대한민국 재택의료 뉴스를 전하는 웹사이트의 **고급 에디토리얼 스타일 초안**입니다.
빌드 도구 없이 브라우저에서 바로 열리는 정적 HTML/CSS/JS로 작성했습니다.

```
web/
├── index.html          홈 (커버스토리 + 지표 + 최신 기사 + 데이터 + 오피니언 + 구독)
├── news.html           전체 기사 목록 (카테고리 필터)
├── article.html        기사 상세 (읽기 진행률, 풀인용, 관련 기사)
├── data.html           데이터 아카이브 (추이 차트 + 권역별 표 + 지표 정의)
├── about.html          저널 소개 (미션 · 편집 원칙 · 제보 · 구독)
└── assets/
    ├── css/main.css    디자인 토큰 + 전체 스타일
    └── js/main.js      테마 토글 · 스크롤 효과 · 필터 · 진행률
```

## 열어보기

```bash
cd web
python3 -m http.server 8080
# http://localhost:8080
```

파일을 더블클릭해서 열어도 동작하지만, `news.html?cat=policy` 같은 주소 파라미터 확인은
로컬 서버로 여는 편이 안정적입니다.

## 디자인 방향

기존 사이트를 "더 고급스럽게" 만들기 위해 잡은 축입니다.

| 요소 | 선택 | 이유 |
|---|---|---|
| 색 | 웜 아이보리 `#fbf9f5` · 딥 잉크 `#12161c` · 브라스 `#a67c2e` | 순백/원색 대신 종이 질감의 저채도 배색으로 신문 지면의 격을 냄 |
| 서체 | 제목 명조 계열 / 본문 고딕 계열 | 국문 명조 헤드라인이 저널의 권위를 만들고, 본문은 가독성 우선 |
| 여백 | 큰 섹션 간격 + 1px 헤어라인 구분선 | 요소를 채우지 않고 비워서 고급감을 만듦 |
| 이미지 | 그라디언트 플레이트(자리표시) | 외부 이미지 의존 없이 톤을 통일. 실사진으로 교체 가능 |
| 모션 | 스크롤 진입 페이드, 마스트헤드 축소 | 과하지 않은 수준. `prefers-reduced-motion` 존중 |

### 구현된 것

- 다크/라이트 테마 토글 (선택값 `localStorage` 저장, OS 설정 자동 감지)
- 스크롤 시 마스트헤드 축소 + 네비게이션 정리
- 뉴스 목록 카테고리 필터 (`news.html?cat=policy` 주소 파라미터 지원)
- 기사 읽기 진행률 바
- 반응형 (모바일 · 태블릿 · 데스크톱)
- 접근성: 건너뛰기 링크, `aria-current` / `aria-pressed`, 차트 대체 텍스트와 표 보기,
  포커스 링, 색만으로 정보를 전달하지 않음

## 콘텐츠에 대한 안내

**기사 제목, 본문, 연락처는 모두 초안용 예시입니다.** 지표는 아래 실제 정책 흐름을
참고해 구성했으나, 게시 전 원문 확인이 필요합니다.

- 장기요양 재택의료센터 시범사업 확대 (2023년 29개소 → 2026년 422개소)
- 「의료·요양 등 지역 돌봄의 통합지원에 관한 법률」 2026년 3월 27일 전면 시행
- 2026년 통합돌봄 예산 914억 원 (전년 71억 원)

## 교체할 자리

1. **브랜드명** — `재택의료저널` / `Homecare Journal Korea` (마스트헤드·푸터)
2. **이미지** — `.plate` 요소를 `<img>`로 교체 (비율 클래스 `ratio-16x9` 등 유지)
3. **연락처** — 주소·이메일·전화번호 (`about.html`, 각 페이지 푸터)
4. **지표** — `data.html`의 차트 수치와 권역별 표
5. **구독 폼** — `data-subscribe` 폼의 전송 처리 (현재는 데모 동작)

## 아임웹으로 옮길 때

현재 사이트가 아임웹 기반이라면, 이 초안은 두 방식으로 활용할 수 있습니다.

- **디자인 시안으로 사용** — 색·서체·여백·섹션 구성을 아임웹 테마 설정과
  디자인 모드에서 재현
- **코드 위젯으로 이식** — 아임웹의 HTML/CSS 삽입 기능에 섹션 단위로 옮김.
  이때 `main.css`의 `:root` 토큰 블록을 먼저 넣어야 색과 서체가 일관되게 적용됩니다.
