# 재택의료NEWS — 홈페이지 리디자인 초안

`https://okidokiokidoki38449.imweb.me/` 의 구조와 콘텐츠를 그대로 유지하면서,
디자인만 고급 에디토리얼 톤으로 다시 만든 초안입니다.
빌드 도구 없이 브라우저에서 바로 열리는 정적 HTML/CSS/JS입니다.

```
web/
├── index.html      홈 — 헤드라인 밴드, HOT 이슈, 우리동네, 가정간호, 사이드바, 검색 서비스, 제보/Q&A, 제휴
├── news.html       전체 기사 (분야 필터, ?cat= 주소 지원)
├── article.html    기사 상세 (읽기 진행률, 사이드바 유지)
├── local.html      우리동네재택의료 — 재택의료센터/가정간호센터/방문진료 검색 3종
├── qna.html        재택의료 Q&A (FAQ 아코디언 + 질문 등록 + 상담 CTA)
├── about.html      회사소개 — 편집 원칙, 제보, 매체 정보
└── assets/
    ├── css/main.css
    └── js/main.js
```

## 열어보기

```bash
cd web
python3 -m http.server 8080     # http://localhost:8080
```

## 원본과의 대응

메뉴, 섹션 순서, 기사 제목, 연락처, 법정 표기는 **원본 그대로** 옮겼습니다.
바뀐 것은 디자인 언어입니다.

| 원본 | 초안 | 이유 |
|---|---|---|
| 밝은 청록 로고 + 남색 히어로 + 연녹색 본문 + 베이지 CTA | 딥 틸 1개 브랜드색 + 웜 아이보리 3단 서피스 | 배경색이 4종으로 갈라져 시선이 분산되던 것을 정리 |
| 본문·제목 모두 고딕 | 제목 명조 / 본문 고딕 | 국문 명조 헤드라인이 매체의 격을 만듦 |
| 카드 테두리·그림자 다수 | 1px 헤어라인 + 넓은 여백 | 요소를 채우지 않고 비워서 고급감 확보 |
| 섹션 제목 단독 | 제목 + 영문 라벨(HOT ISSUE 등) | 지면 리듬과 위계 강화 |

### 구현된 기능

- 라이트/다크 테마 토글 (선택값 `localStorage` 저장, OS 설정 자동 감지)
- 스크롤 시 마스트헤드 축소
- 기사 목록 분야 필터 (`news.html?cat=hot` 등 주소 파라미터 지원)
- 기사 읽기 진행률 바, 사이드바 sticky
- 지역 검색 폼 + 결과표 (UI 골격, 데이터 연동 전)
- Q&A 아코디언
- 반응형 (모바일·태블릿·데스크톱)
- 접근성: 건너뛰기 링크, `aria-current`/`aria-pressed`, 표 캡션, 포커스 링,
  `prefers-reduced-motion` 및 JS 비활성 폴백

`import-images.py`(사용법은 파일 상단 docstring 참고)로 내려받았습니다.
`images.tsv`에 33개 자리 전부의 원본 URL을 기록해 두었으니, 다시 받아야 할 때는
`python3 import-images.py images.tsv`만 실행하면 됩니다. 원본 PNG은 1MB를 넘는
것도 많아, 내려받은 뒤 폭 1400px·JPEG q82로 다시 인코딩합니다(로고·배너처럼
투명도가 필요한 파일은 PNG 유지). 이미 `<img>`로 바뀐 자리는 다시 실행해도
건드리지 않습니다.

## 교체할 자리

1. **로고** — 현재는 CSS로 만든 텍스트 로고. 실제 로고 이미지로 교체 가능
2. **기사 링크** — 모든 기사가 `article.html` 하나를 가리킵니다
3. **검색 데이터** — `local.html`의 결과표는 화면 확인용 예시 값
4. **폼 처리** — 구독·질문 등록은 데모 동작 (`data-subscribe`)
5. **아직 사진을 못 넣은 개별 페이지** — `/home-healthcare-news`, `/home-care-tracker`,
   `/my-home-care`, `/home-nursing`, `/homecare-faq`, `/health`, 개별 기사 상세
   페이지의 원본은 egress 정책으로 아직 못 읽었습니다. 페이지 소스를 붙여넣어
   주시면 같은 방식으로 반영합니다.
